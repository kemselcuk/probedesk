# UI-04 — Plan Editor bilgi hiyerarşisi

Tarih: 2026-11-04. Durum: uygulama tamamlandı, ayrı teknik inceleme bekliyor.
Kapsam: `features/plans/plan-editor-page.*`, `plan-draft-form` doğrulamaları ve ilgili testler.
Fixture: izole `probedesk_e2e_test` veritabanı, ayrı API (:3101) ve web (:4302). Kullanıcı
delivery veritabanına yazılmadı.

## Uygulananlar

- Üst kart 139 px: solda plan adı alanı, sağda device profile. Altında tek metadata şeridi:
  Published version, Draft revision, Draft steps, Total samples, Nominal duration. Dört ayrı
  büyük özet kartı ve ayrı totals kartı kaldırıldı.
- Alan yerleşimi 12 kolon: ad 8 / birim 4; min 3 / max 3 / örnek 3 / aralık 3. Böylece
  masaüstünde iki mantıksal satır oluşuyor; 768 px'te ad ve birim tam satır, min/max ve
  örnek/aralık ikili; 390 px'te tek kolon.
- Adım başlığı sıra + ad + birim + kompakt örnek/süre + eylemler. Sürükleme tutamacı 32×36,
  yukarı/aşağı 32×32 ikon düğmeleri, çöp kutusu ikonunun erişilebilir adı var.
- Uzun alan hint'leri kaldırıldı; "Field limits" disclosure'ında 6 ondalık, 1–1.000 örnek,
  100–5.000 ms sınırı bir kez anlatılıyor. Hata metinleri alan altında kalıyor.
- Dirty/saving durumu 22 px badge (warning/primary/success); Save draft primary, Publish
  outlined. 0 adımda Publish engeli, dirty iken "Save your changes before publishing",
  validation özeti ve odak korunuyor.
- CDK drag-drop ve klavye taşıma aynı FormArray sırasını değiştiriyor; taşınan satırın
  touched/dirty/hata bilgisi ve `clientId` kimliği korunuyor, odak taşınan başlığa gidiyor.
- 409 çakışmasında panel `role=alert` + `tabindex=-1` ile odaklanıyor, yerel plan adı
  korunuyor, "Reload saved draft" akışı duruyor.
- Unsaved guard dialogu 460 px, 8 px radius, 18/24 başlık; "Keep editing" ilk odak.
- Yayımlanmış sürümler listesi ortak `.pd-version-*` görsel diline geçti; Current badge
  22 px. Save bar sayfa sonunda, sticky değil; içeriği örtmüyor.

- Klavye "Move step 1 down": sıra `Current Draw, Untitled step, Case Temperature` oldu;
  odak `step-heading-…` üzerinde, announcement "Step moved to position 2 of 3.",
  dirty badge "Unsaved changes".
