# UI-07 — Compare Runs ve ortak grafik tasarımı

Tarih: 2026-11-05. Durum: uygulama tamamlandı, ayrı teknik inceleme bekliyor.
Kapsam: `features/comparisons/compare-runs-page.*`, `comparison-step-card.*`,
`shared/charts/comparison-chart.*` ve karşılaştırma grafik paleti.
Fixture: izole `probedesk_e2e_test`, API (:3101), web (:4302), Operator;
`Power Supply Validation` v2 (Passed) ve v1 (Failed) çifti.

## Uygulananlar

- Header tek satır: Change runs primary; Swap sides / Clear comparison / Reload
  comparison sakin text düğmeler. Ayrı "Back to Run History" düğmesi kaldırıldı;
  sidebar ve hata durumlarındaki Run History bağlantıları duruyor.
- İki 426 px run kartı yerine 161 px kompakt bant: plan/sürüm + status badge,
  tek satır `samples · out of tolerance · seed · steps`, partial chip ve kısa
  data note. Tam metadata (started/finished/run id/reason) kart içindeki
  "Metadata" disclosure'ında. "Open run details" aynı satırda.
- Version ve scenario notları tek "Version and scenario notes" disclosure'ına
  alındı; iki ayrı not şeridi sayfa yüksekliğinden çıktı. Aynı/farklı sürüm
  metinleri erişilebilir kaldı.
- Dört sayaç (Shared / right-only / left-only / changed fields) tek 38 px
  satırda; Changed rule fields özeti grafiklerden önce duruyor.
- Üç ayrı adım kartı yerine adım şeridi: seçili adımın kartı görünür, diğer
  kartlar DOM'da kalır ve seçimde yeniden boyutlanır. Varsayılan ilk adım.
  `aria-pressed` + `aria-controls` ile klavye erişimi var.
- Her adımda önce başlık/kural farkı, sonra grafik; "Rule comparison and stored
  evaluation" ve "Recorded measurements by run" bölümleri kapalı disclosure.
  Böylece ilk grafik 1280×800'de y708'de başlıyor (önce 1261) ve sayfa
  11.443 px'den 1.213 px'e indi.
- Grafik: sol seri primary blue `#2563eb` düz, sağ seri amber `#b45309` kesikli;
  her run kendi tolerans bandını koruyor. Aynı birimde iki seri; birim
  değişiminde iki ayrı `MeasurementChart` paneli ve delta yok; eklenen/çıkarılan
  adım tek taraflı, sıfır doldurma yok. Karşılaştırma tablosundaki delta yalnız
  API'nin hesapladığı değer.
- Grafik yüksekliği 300/240/220 px (desktop/tablet/mobil); eksen ve legend
  12 px; caption tek satır. Reset view, seri göster/gizle, wheel zoom/pan
  korunuyor. Grafik noktası seçimi artık ilgili run'ın measurements
  disclosure'ını açıp tam sample satırını odaklıyor; satır ID'si
  `comparison-measurement-<runStepId>-<sampleIndex>`.
- Seçim paneli: kısa şart metni, iki eşit picker, Compare / Clear / Cancel;
  uzun "latest 100" paragrafı kısaltıldı. Boş linkte panel otomatik açık.
