# UI-06 — Run History ve Run Details yoğunluğu

Tarih: 2026-11-05. Durum: uygulama tamamlandı, ayrı teknik inceleme bekliyor.
Kapsam: `features/runs/run-history-page.*`, `run-details-page.*` ve ortak
`.pd-table-wrap`/measurement chart sunumu.
Fixture: izole `probedesk_e2e_test`, API (:3101), web (:4302), Operator.
Seed'in 4 run'ına ek olarak UI-05 canlı izleme kontrolünde başlatılan 1 NORMAL
run vardır; kullanıcı delivery veritabanına yazılmadı.

## Uygulananlar

- **Run History** başlığı tek satıra indi. Filtre kartı 222 px'den 114 px'e
  düştü: Plan/Status/Outcome ilk satır, From/To + kısa `[From, To)` UTC notu
  ikinci satır. Büyük "Filters" başlığı ve URL davranışı paragrafı kaldırıldı;
  aynı metin ekran okuyucu için görünmez hint olarak duruyor.
- Karşılaştırma alanı tek 46 px satır: seçim özeti + Compare + Clear selection.
  Boş/tek seçimde gerekçe gri hint olarak görünür; yalnız gerçek geçersiz
  eşleşmede kırmızı. Boş seçim artık hata gibi okunmuyor.
- History tablosu 10 kolondan 7 kolona indi: Compare, Result, Plan/version,
  Scenario/seed, Started UTC, Samples/OOT, Details. Finished ve ayrı First
  failure kolonu kaldırıldı; ilk failure bilgisi plan hücresinde kompakt satır,
  finished/full timestamp ve tüm ölçümler Details sayfasında erişilebilir.
- Tablo başlığı 36 px, normal kayıt 55 px, failure'lı kayıt 89 px, cancelled
  kayıt 81 px. 1280'de tablo 1006 px, kapsayıcı 1008 px: yatay scroll yok.
  768/390'da yalnız tablo kapsayıcısı scroll ediyor; sayfa taşmıyor.
- Başlangıç zamanı tek satır `Nov 4, 17:46 UTC`; tam değer `title` ve Details
  metadata'sında. `Samples / OOT` başlığındaki kısaltmanın tam açılımı görünmez
  metinle erişilebilir.
- **Run Details** özeti 679 px yerine 1280'de 213 px: plan/sürüm/scenario ve
  run id, status badge, tek satır durum açıklaması, kayıt/örnek ilerlemesi,
  4 alanlı sonuç şeridi (OOT, partial samples, duration, first failure).
  Seed, profil, simulator/evaluation sürümü, requested by, başlangıç/bitiş ve
  event sequence "Run metadata" disclosure'ında.
- Başarısız run varsayılan olarak ilk out-of-tolerance adımı (Step 2: Current
  Draw) açıyor; başarılı run ilk adımı. Adımlar yatay sekme şeridiyle seçiliyor;
  her adımın paneli DOM'da kalıyor, yalnız seçili panel görünüyor.
- Seçili adımda tek satır kural özeti (tolerans, sample, interval, recorded),
  grafik, "Step rules and stored statistics" disclosure'ı ve measurements
  tablosu var. 90 örnekli üç adımın tabloları aynı anda açık değil; veri
  silinmedi.
- Grafik alanı üst kenarı 1280×800'de **y515** (hedef ≤520), ölçülen grafik
  canvas'ı 982×300. Grafik başlığı tek satır caption'a indirildi.
- İlk failure aksiyonu doğru adımı açıp sample 14 satırını odaklıyor; chart
  "View measurements in the table" doğru tabloyu açıp odaklıyor. Adım
  değişiminde Chart.js canvas'ı ResizeObserver ile 982×300'e yeniden çiziliyor.
- Run again kartı adımlardan sonraya taşındı; özet ilk görünümde ölçüme yer
  açıyor. Cancel yine destructive secondary outlined; rol notları tek satır.
- Ortak `.pd-table-wrap` `contain: paint` aldı; geniş tablo kapsayıcısı kendi
  içinde scroll ederken shell-content scrollWidth'i 390'da 390 kaldı.
