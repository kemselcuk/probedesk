# UI-05 — Start Run ve Live Run

Tarih: 2026-11-04/05. Durum: uygulama tamamlandı, ayrı teknik inceleme bekliyor.
Kapsam: `features/runs/start-run-page.*`, `live-run-page.*` ve
`shared/charts/measurement-chart.scss` sunum katmanı.
Fixture: izole `probedesk_e2e_test` veritabanı, ayrı API (:3101) ve web (:4302).
Operatör demo hesabı kullanıldı; kullanıcı delivery veritabanına yazılmadı.

## Uygulananlar

- **Start Run** iki kolona ayrıldı: solda Run settings (1280'de 659 px), sağda
  published plan özeti (329 px). 1099 px altında tek kolon. Form artık ilk
  görünümde tamamen erişilebilir; Start run düğmesi 1280×800'de y 345.
- Plan özeti tek beyaz kart: plan adı, Version badge, üç sayısal özet
  (Steps / Total samples / Nominal duration) ve kompakt adım tablosu. Tablo iki
  kolon: adım adı + birim/tolerans/aralık detayı, sağda sample sayısı. Tam
  ondalık değerler korunuyor. Version ID ve immutable açıklaması "Version
  details" disclosure'ında.
- Uzun "API decides…" alt başlığı ve "immutable rules" paragrafı ürün
  yüzeyinden kaldırıldı; ikincisi disclosure içinde bir kez anlatılıyor.
  Senaryo/seed hint'leri kısaltıldı; hata metinleri ve `aria-describedby`
  bağları aynı kaldı.
- **Live Run** üst özeti 538 px'den 239–289 px'e indi: plan/sürüm/ilerleme,
  kompakt durum ve bağlantı rozetleri, tek progress şeridi, partial/terminal
  uyarısı. Teknik alanlar (seed, event sequence, başlangıç/bitiş, run ID)
  "Run metadata" disclosure'ında; durum açıklaması tekrarı kaldırıldı.
- Live adım listesi kart yığını yerine tek çerçeveli kompakt liste: 71 px
  desktop satır, solda adım/unit/aralık, sağda durum + outcome rozetleri ve
  Recorded / Out of tolerance / First failure sayaçları. RUNNING satırı
  primary, hata/iptal satırları warning/danger sol işaret kullanıyor.
- Ölçüm grafikleri hâlâ her adım için çiziliyor; 30 satırlık tablolar
  "Recorded measurements (N samples)" disclosure'ına alındı. Böylece Live
  bölümü ~5.450 px yerine ~1.800 px; tüm örnekler DOM'da ve erişilebilir.
  Chart "View measurements in the table" ve failure-sample seçimi disclosure'ı
  otomatik açıp doğru tabloyu/satırı odaklıyor.
- Ölçüm grafiği tipografisi/boşlukları ortak token'lara geçti; grafik
  yüksekliği desktop 300, 768'de 240, mobilde 220 px. Chart.js davranışı,
  tolerans bandı ve backend verdict'i değişmedi.
- Cancel run artık destructive secondary (outlined danger), live header'da
  Back / View details ile aynı sırada. Rol notu yalnızca yetkisiz rolde ve tek
  satır.

## Açık bulgular

- Live grafikleri üç adımın tamamı için çiziliyor; bu nedenle grafik bölümü
  doğal olarak ~1.8k px. Ölçüm tabloları disclosure'a alındı, recent
  measurements y 2.493'e indi; veri saklanmadı.
- RUNNING kanıtı için izole E2E veritabanında bir NORMAL run başlatıldı
  (`be32a8b6…`). Bu, seed'in 4 run'lık tabanına geçici bir 5. run ekler;
  kullanıcı verisi değildir.
- Active-run 409, cancel dialog ve SSE reconnect görsel olarak bu turda tekrar
  üretilmedi; ilgili Angular testleri (start/live spec) geçiyor ve davranış
  kodu değişmedi.
- 100 karakterlik plan/adım adı bu ekranda ayrı fixture ile denenmedi; mevcut
  `overflow-wrap: anywhere` ve 390 px ölçümü taşma göstermedi. UI-08'de uzun
  içerik kontrolü yapılacak.
