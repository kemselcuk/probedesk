- Ortak pd-table ilk/son hücre16px; gövde dikey padding10px, iç kolonlar12px. Son kolon sağda; action label, negatif button iç padding telafisiyle aynı sağ çizgiye gelir. - Run rozetleri34px yerine24px; successyeşil, failurekırmızı, interruptedamber. History Cancelled artık plan adına binmez.
- Material floating label16px tanım×0.75transform=gerçek12px. Helper/error line-height20px ve üst4px; Compare açıklama→kontrol16px, kontrol→not12px ve iki kontrol arası16px. Teknik uygulama açıklamaları seçim panelinde kısaltıldı. Compare adım kartına eksik16px padding eklendi.
- MatSelect native fieldset disabled özelliğini miras almadığı için Start'ta Operator dışı form da disabled yapılır; submit/backend rol kontrolleri korunur.
