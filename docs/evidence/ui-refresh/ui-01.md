# UI-01 — ortak tasarım tokenları ve Material ölçeği

Tarih: 2026-11-04. Durum: uygulama tamamlandı, ayrı teknik inceleme bekliyor.
Kapsam: `styles/_tokens.scss`, `styles/_material-theme.scss`, `styles/_primitives.scss`,
`styles.scss`, `shared/ui/page-header` ve ortak durum bileşenleri.

## Uygulananlar

- Tek token kaynağı: yüzey/metin/primary/semantik renkler, 4–32 px boşluk ölçeği,
  6/8 px radius, toolbar 52, sidebar 224, nav 36, sayfa 24, kart 16, kontrol 40, düğme 36,
  tablo başlığı 36, tablo satırı 44 ve tipografi ölçüleri (`14/20` gövde, `24/32` h1,
  `13/20` tablo, `12/16` metadata).
- `mat.theme` global density `-1`; form field yalnızca belgelenmiş
  `mat.form-field-overrides` tokenlarıyla 40 px görsel yüksekliğe ve 12 px metadata
  subscript'ına ayarlandı. Button, card, dialog, toolbar, checkbox, sidenav ve spinner
  özelleştirmeleri de `mat.*-overrides` public API'siyle yapıldı.
- `subscriptSizing="dynamic"` kullanıldı: boş alanlar 40 px kalır, hint/error geldiğinde
  subscript eklenir. Private `.mat-mdc-form-field-subscript-wrapper` selektörü yok.
- Global CSS scale, `zoom`, `transform: scale`, kök font küçültme, `::ng-deep` ve yaygın
  `!important` kullanılmadı.
- Font ailesi `Inter` varsa yerel, yoksa system UI fallback; dış font ağı veya yeni npm
  bağımlılığı yok.
- Odak halkası 2 px primary + 2 px offset; coarse pointer'da Material düğmeleri 44 px hedefe
  çıkar. Reduced motion tercihinde geçişler kapatılır.
