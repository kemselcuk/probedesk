## Uygulanan davranış

- Start isteğinde isteğe bağlı cihaz/parti; metadata yokken eski v1 hash aynı kalır, metadata ile v2 canonical UUID/batch key kullanılır. Cihazın adı/seri numarası hash girdisi değildir.
- Replay arşiv/yeniden adlandırma doğrulamasından önce yapılır; mevcut çalışmaya döner. Yeni run cihazı transaction içinde FOR SHARE kilitler; Device mutasyonları FOR UPDATE ile aynı satırda sıralanır.
- Cihazsız snapshot Prisma.DbNull ile SQL NULL olur. Run/adımlar/ilk event/snapshot atomik oluşur. Live/SSE public event sözleşmesi korunur.
- Snapshot/history/comparison required nullable deviceId/deviceSnapshot/batchNumber döndürür; canlı cihaz join edilmez. Eski kayıtlar null döner.
- History cihaz/parti/yayımlanmış sürüm/senaryo filtreleri count ve page sorgusunda aynı where kullanır. Tarih aralığı [from,to), sıra startedAt DESC/id DESC. Plan-sürüm uyuşmazlığı field error; bilinmeyen filtre UUID boş sonuç.
- Lead OpenAPI ve istemci tiplerini üretim komutlarıyla yeniledi. Frontend runtime parser metadata alanlarını zorunlu nullable doğrular; snapshot kimlik tutarsızlığı ve eksik alanları hata yapar. Eski fixture'lar explicit null içerir; history client yeni filtreleri iletir.
