## İlk UI dilimi

- Lazy `/devices` ve `/devices/:deviceId` route'ları; sidebar Devices. Overview/root redirect EX-09'da eklenecek.
- Generated tipli DevicesApi; required nullable alanlar, Unicode code point sınırları, UUID/response identity, revision ve sayfa yanıtları runtime doğrulanır. Eksik nullable alan sessizce tamamlanmaz.
- Liste arama/state/page URL kaynaklı; filtre değişiminde switchMap eski HTTP'yi iptal eder. Loading/empty/error/invalid URL ve sayfa dışı sonuçlar ayrıdır. Profil adı hata/retry durumu vardır.
- Planner create/edit Material dialog: typed form, trim/code-point/serial doğrulaması, server field errors ve pending/close/duplicate koruması. Conflict girdileri korur; kullanıcı Load current device ile yeni revision ve veriyi açıkça yükler.
- Cihaz ayrıntısı güncel metadata, UTC tarihler, profil ve durum gösterir; archive/restore açıklamalı confirmation dialog ve expectedRevision kullanır. Operator/Viewer mutasyon eylemlerini görmez.
- Ayrıntıdan `/runs?deviceId=...` aynı geçmiş ekranına gider. Geçmiş deviceId'yi URL'den okuyup count/page API sorgusuna taşır, diğer filtre/pagination geçişlerinde korur; Clear filters kaldırır. Satır plan/sürüm altına cihazın snapshot adı/seri ve batch/legacy null açıklaması eklenir.
- Mevcut token/typography/table padding kullanılır; cihaz tablosu yalnız kendi scroll bölgesinde kayar. Gerçek responsive/klavye/görsel kontrol henüz yapılmadı.
