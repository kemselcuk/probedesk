## Amaç ve çıktı

Material tema, ana düzen, route'lar, bildirim ve ortak loading/empty/error bileşenlerini oluştur.

## Değişiklik alanı

- `apps/web/src/app/core/`
- `apps/web/src/app/shared/`
- `apps/web/src/app/`

## Kabul ölçütleri

- [ ] Deep link ve sayfa yenilemesi doğru route'u açar.
- [ ] Navigasyon klavyeyle kullanılabilir; kullanıcı metinleri İngilizcedir.
- [ ] Hata/boş/yükleme görünümleri birbirinden ayırt edilir.
- [ ] Uygulama kapsamı dışında tasarım sayfaları eklenmez.

## Doğrulama

- npm run test:web; npm run build.
- Navigasyon/odak ve route smoke kontrolü.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
