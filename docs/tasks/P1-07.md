## Amaç ve çıktı

Typed login formu, oturum yükleme, route guard, rol navigasyonu ve logout'u uygula.

## Değişiklik alanı

- `apps/web/src/app/core/auth/`
- `apps/web/src/app/features/auth/`

## Kabul ölçütleri

- [ ] Hatalı giriş anlaşılır; gönderimde tekrar istek engellenir.
- [ ] Yenilemede me ile oturum yüklenir; sona ermede kontrollü giriş akışı oluşur.
- [ ] Rol dışı işlemler UI'da kullanılamaz; backend yetkisi ayrıca korunur.
- [ ] CSRF düzeni ve göreli /api istekleri uyumludur.

## Doğrulama

- npm run test:web; auth HTTP/guard/form testleri.
- Üç hesapla giriş/çıkış ve sayfa yenileme smoke kontrolü.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
