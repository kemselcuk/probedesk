## Amaç ve çıktı

Snapshot özeti, refresh, rol kontrollü cancel ve Run Again akışını oluştur.

## Değişiklik alanı

- `apps/web/src/app/features/runs/`

## Kabul ölçütleri

- [ ] Operator iptal eder; diğer roller yalnızca izler.
- [ ] İptal tıklaması gerçek terminal durum gibi iyimser gösterilmez.
- [ ] Cancelled/Interrupted/Error ve kısmi adımlar doğru açıklanır.
- [ ] Run Again yeni anahtar/run oluşturur; eski kayıt korunur; ayarlar görünürdür.

## Doğrulama

- Bileşen/HTTP hata testleri; terminal-null outcome gösterimi.
- Aşama 3 başlat/sonuç/iptal/kesinti demosu.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
