## Amaç

Run History ve Run Details yoğunluğu; ana plandaki bu ekrana/bileşene ait ölçü, hiyerarşi ve davranış koruma maddelerinin tamamını uygula. Aşağıdaki özet ana planın yerini almaz.

## Kabul ölçütleri

- [ ] History filtre/selection şeridi kompakt; boş seçim kırmızı hata değil; yanlış seçim gerçek hata.
- [ ] 1280 px’de ilk kayıt y≤400,768 px’de y≤560; ana kolonlar1280 px’de sığar, sadece table wrapper gerektiğinde scroll.
- [ ] Details özet 160–220px; teknik metadata disclosure; seçili adım/grafik/ölçüm önce, grafik y≤520.
- [ ] Failure→step→sample focus/scroll/disclosure açılışı, filtre URL/back/page ve partial-null kayıtlar korunur.

## Doğrulama ve kanıt

- İlgili Angular testleri, lint/typecheck ve değişiklik alanına uygun build.
- Gerçek browser: ölçü, taşma, label/error/focus ve önce/sonra PNG.

- Sadece gerçekten çalıştırılan komutun sonucunu yaz; görsel kabulü test yeşiline eşitleme.
