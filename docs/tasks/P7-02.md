## Kabul ölçütleri

- [x] Viewer run başlatamaz; Operator plan değiştiremez. — `apps/api/test/security.e2e-spec.ts` rol matrisi; mevcut `runs.e2e-spec.ts`, `plans.e2e-spec.ts` ve `plan-publish.e2e-spec.ts` testleriyle birlikte.
- [x] Sahte status/outcome/verdict alanları reddedilir. — `security.e2e-spec.ts` sunucu alanı tablosu; plan create/save/publish ve run start gövdelerinde status, outcome, verdict, createdBy, publishedBy, timestamp ve requestedBy alanlarının tamamı `UNKNOWN_FIELD` ile 400; nested adım alanları da reddediliyor.
- [x] Eksik/yanlış CSRF ve origin güvenli biçimde reddedilir. — Yedi mutasyon için eksik/yanlış CSRF ve yabancı Origin ayrı ayrı 403; doğru imzalı istek geçiyor. Authenticated mutasyonlarda eksik olan Origin kontrolü `apps/api/src/auth/origin.ts` ile eklendi.
- [x] Hassas veriler yanıt/loga sızmaz; auth kaybı UI'da açıklanır. — Backend kısmı `security.e2e-spec.ts` ve `MemoryLogger` ile doğrulandı. UI auth kaybı bu worker'da değiştirilmedi; mevcut `auth.interceptor.spec.ts` / `auth.guards.spec.ts` hedefli koşusu (4 dosya/30 test) ve P4-07 gerçek Chrome kanıtı kapsıyor.

## Doğrulama

- T24 ve auth negative API matrisi. — `security.e2e-spec.ts` (7 test), tam e2e suite 21 dosya/195 test.
- Rol dışı deep link ve cookie/session expiry tarayıcı kontrolleri. — Bu kartın backend kapsamı dışında; P7-04/P7-06 ve P4-07 kanıtlarına bırakıldı. Bu turda UI kodu değiştirilmedi.
