  - FORCED_FAILURE: hedef adımda `floor((sampleCount - 1) / 2)` indeksi; `distance = max(ceil((maximum - minimum) / 2), 0.000001)` mikro birim; değer `maximum + distance`. Demo Current Draw (0.45–0.55, 30 örnek) indeks 14 değeri tam `0.600000`.
