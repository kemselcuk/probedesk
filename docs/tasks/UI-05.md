## Amaç

Start Run ve Live Run görünümü; ana plandaki bu ekrana/bileşene ait ölçü, hiyerarşi ve davranış koruma maddelerinin tamamını uygula. Aşağıdaki özet ana planın yerini almaz.

## Kabul ölçütleri

- [ ] Start form+plan özeti dengeli; scenario alanları, idempotency, activeRun bağlantısı ve doğal Live navigasyonu korunur.
- [ ] Live üstte kısa status/connection/progress; adım ve grafik önce; açıklama ve kart tekrarı azaltılmış.
- [ ] Cancel/operator yetkisi, reconnect/session loss, terminal final snapshot unavailable ve partial state açık.
- [ ] Canlı çizim her örnekte scroll/focus zıplatmıyor; backend verdict/hassasiyet/teardown aynen korunuyor.
