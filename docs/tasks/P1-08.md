## İnceleme ve kanıt kaydı

- Uygulama commit'i: Bu değişiklikle eklenecek; lead commit/push sonrasında SHA buraya işlenecek.
- Çalıştırılan kontroller ve gerçek sonuçları (npm komutları `CI=true npx --yes npm@11.6.2` ile):
  - `prettier --check .github/workflows/ci.yml` → biçim uyumlu.
  - `go run github.com/rhysd/actionlint/cmd/actionlint@latest .github/workflows/ci.yml` → çıktı yok, çıkış kodu 0 (actionlint 1.7.12).
  - `npm run lint --workspace apps/api` → auth değişiklikleri sonrası 58 dosya, 0 uyarı/0 hata.
  - `npm run typecheck --workspace apps/api` → çıkış kodu 0.
  - `npm run test --workspace apps/api -- --reporter=default --reporter=junit --outputFile.junit=test-results/junit.xml` → auth değişiklikleri sonrası 5 dosya, 22 test geçti; JUnit yazıldı.
  - `npm run build --workspace apps/api` → `nest build` çıkış kodu 0.
  - `npm run lint --workspace apps/web` → auth değişiklikleri sonrası 43 dosya, 1 uyarı/0 hata; çıkış kodu 0.
  - `npm run typecheck --workspace apps/web` → çıkış kodu 0.
  - `npm run test --workspace apps/web -- --watch=false --reporters=default --reporters=junit --output-file=test-results/junit.xml` → auth değişiklikleri sonrası 11 dosya, 56 test geçti; JUnit yazıldı.
  - `npm run build --workspace apps/web` → `ng build` başarılı; 501.15 kB initial raw / 117.06 kB tahmini transfer; 500 kB uyarı bütçesi 1.15 kB aşıldı, hata bütçesi aşılmadı.
  - `npm run db:migrate:test --workspace apps/api` → yerel `postgres:18.1-alpine` üzerinde başarılı; 2 migration bulundu, yeni auth migration'ı uygulandı.
  - `npm run test:e2e --workspace apps/api -- --reporter=default --reporter=junit --outputFile.junit=test-results/junit.xml` → auth öncesi 24 test geçti; auth sonrası tekrar 2 dosya başarısız, 25 test geçti, 10 atlandı (`SessionAuthGuard`/`AuthService` çözümlemesi ve commit edilmiş OpenAPI belgesinin eski olması).
  - `npm run openapi:check` → auth öncesi geçti; auth rotaları eklendikten sonra OpenAPI e2e senkron testi başarısız. Güncel ağaçta `openapi:check` çalıştırılmadı; dosyayı yazdığı için auth sahibinin alanına dokunmamak adına beklendi.
  - `npm ci` ve gerçek GitHub Actions koşusu → henüz çalıştırılmadı; lead push'u sonrasında doğrulanacak.
