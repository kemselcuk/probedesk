## Kabul ölçütleri

- [ ] Senaryoya göre alanlar değişir; uygunsuz alanlar gönderilmez.
- [ ] Çift tıklama duplicate run oluşturmaz; retry aynı idempotency anahtarını korur.
- [ ] Aktif çalışma hatası mevcut kayda bağlantı verir.

## Doğrulama

- Typed form ve HTTP success/409/network error bileşen testleri.
- Normal/forced/random payload'larını doğrula.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
