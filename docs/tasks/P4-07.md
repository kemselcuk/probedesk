## Amaç ve çıktı

İki izleyici, route geçişi, geri dönüş ve logout/expiry akışlarını doğrula.

## Değişiklik alanı

- `tests/e2e/`
- `apps/web/`

## Kabul ölçütleri

- [ ] İki sekme aynı kalıcı sonuca ulaşır.
- [ ] Ekrandan ayrılmak testi durdurmaz; dönüş yeni run başlatmaz.
- [ ] Kapanan ekranın stream/aboneliği yeni olay işlemeyi bırakır.
- [ ] Logout/expiry uygun bağlantıyı kapatır; diğer geçerli izleyiciyi bozmaz.

## Doğrulama

- T16; iki browser context ve route lifecycle kontrolleri.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
