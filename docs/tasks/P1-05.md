## Amaç ve çıktı

OpenAPI çıktısı ve üretilen istemci tipleri için deterministik üretim/güncellik kontrolü kur.

## Değişiklik alanı

- `packages/api-client/`
- `apps/api/`
- `package.json`

## Kabul ölçütleri

- [ ] Aynı sözleşme aynı dosyaları üretir.
- [ ] Sözleşme değişip istemci güncellenmezse kontrol başarısız olur.
- [ ] Angular Prisma/Nest sınıflarını doğrudan import etmez.
- [ ] SSE tiplerinin kaynağı REST üreticisi desteklemiyorsa ayrıca belgelenir.

## Doğrulama

- İstemciyi üret; tekrar üretimde fark olmadığını doğrula.
- Kontrollü sözleşme değişikliğinde npm run openapi:check başarısız olmalı.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
