## İnceleme ve kanıt kaydı

- Uygulama commit'i: Henüz yok; commit/push lead'in sorumluluğunda.
- Çalıştırılan kontroller ve gerçek sonuçları: Ayrıntılı komut ve çıktılar
  [phase-8-compose.md](../evidence/phase-8-compose.md) içinde. Özet:
  - `docker compose --profile delivery config --quiet` — çıkış 0;
    `delivery` profili `postgres`, `migrate`, `api`, `web` servislerini veriyor;
    profilsiz `docker compose config --services` yalnızca `postgres` veriyor.
  - `docker compose --profile delivery build --no-cache` — çıkış 0,
    gerçek süre 159.85 s (temel imajlar yerelde mevcutken). İmaj boyutları:
    API 485 MB, web 93.3 MB, migrate 1.11 GB.
  - `docker compose --profile delivery up -d` — migrate `Exited (0)`, API
    `healthy`, web `healthy`; sıra postgres → migrate → API → web olarak
    gözlendi. Migration çıktısı: 8 migration, "No pending migrations to apply."
  - `curl` (web 8080): `/api/health/live` 200 `{"status":"ok"}`;
    `/api/health/ready` 200
    `{"status":"ok","checks":{"database":"ok","migrations":"ok"}}`.
  - Üç demo hesabıyla web proxy üzerinden giriş: planner, operator, viewer
    hepsi 200; oturum cookie'si HttpOnly, `XSRF-TOKEN` okunabilir. Sahte
    Origin 403, yanlış parola 401.
  - Gerçek Chromium: `/runs/:id` deep link'i `/login?returnUrl=...`'e gidiyor;
    giriş sonrası aynı run detayı açılıyor; tam sayfa yenilemede oturum ve
    detay korunuyor. `document-title: Run Details · ProbeDesk`.
  - Gerçek NORMAL run (`Power Supply Validation` v2, seed 42):
    POST 202, `run.completed` ile `COMPLETED/PASSED`, 90/90 örnek, son event
    sequence 98. SSE `curl -N` akışında 98 çerçeve; ilk replay 0.006 s'de,
    canlı çerçeveler ~0.206 s medyan aralıkla ve son çerçeve 17.160 s'de
    geldi. `Transfer-Encoding: chunked`, `Content-Encoding` yok (gzip kapalı).
  - `docker compose down` (volume'e dokunmadan) + `up -d` sonrası planlar 3,
    run'lar 41, doğrulama run'ı aynı `COMPLETED/PASSED`/90 örnek; volume
    oluşturma zamanı `2026-11-03T13:32:40Z` değişmedi; API container ID'si
    değişti, eski oturum `/api/auth/me` 200.
  - `docker top probedesk-api-1` — tek `node dist/main.js` süreci, uid 1000,
    container `User=node`; API host portu yok, web `127.0.0.1:8080`,
    PostgreSQL `127.0.0.1:5434` (yerel `.env`; varsayılan 5432).
  - Compose log taraması: parola/cookie/token/DATABASE_URL için 0 eşleşme;
    ERROR/WARN satırı yok.
