## Amaç ve çıktı

Web/proxy, API, PostgreSQL ve başlangıç migration işini tek yerel demo düzeninde sun.

## Değişiklik alanı

- `compose.yaml`
- `infra/docker/`
- `infra/nginx/`
- `apps/api/`
- `apps/web/`

## Kabul ölçütleri

- [ ] Belgelenen Compose girişi host Node/PostgreSQL gerektirmez.
- [ ] Startup sırası, health ve recovery readiness doğru çalışır.
- [ ] Deep link yenileme ve proxy üzerinden canlı SSE çalışır; buffering yoktur.
- [ ] Named volume ve localhost portları belgeli; tek API süreci çalışır.

## Doğrulama

- Release image build/start ve SSE/deep link smoke kontrolü.
- Container loglarında hassas bilgi olmadığını incele.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
