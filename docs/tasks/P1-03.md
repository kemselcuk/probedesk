- Çalıştırılan kontroller ve gerçek sonuçları (2026-11-03):
  - `npm run test --workspace apps/api` → 3 dosya, 16 unit test geçti (env validation, test DB guard, mevcut controller testi).
  - `npm run test:e2e --workspace apps/api` → 5 dosya, 24 Supertest/entegrasyon testi geçti. Kapsam: geçersiz/eksik alan, bilinmeyen alan, nested field path (`steps.0.measurement.value`), non-finite JSON (`1e999`), request-id geri dönüşü ve güvensiz header değişimi, live/ready 200/503, 404 ve 500 ortak hata gövdesi, SQL/stack/token sızıntısı kontrolü, OpenAPI dokümanı.
  - Başlangıç testleri: eksik `DATABASE_URL` + geçersiz `PORT` ile süreç exit≠0 ve "Invalid environment configuration" / `DATABASE_URL` / `PORT` mesajları; geçersiz `mysql://...supersecret...` URL'si ile çıktıda `supersecret` yok.
  - `PORT=3101 node apps/api/dist/main.js` (DB açık) → `/api/health/live` 200 `{"status":"ok"}`, `/api/health/ready` 200 `{"status":"ok","checks":{"database":"ok"}}`, `/api/docs-json` 200.
  - Dev ve test PostgreSQL container'ları durdurulmuşken `PORT=3102 node apps/api/dist/main.js` → `/api/health/live` 200 `{"status":"ok"}`; `/api/health/ready` 503 `{"code":"SERVICE_UNAVAILABLE","message":"The service is not ready.","requestId":"9bfc82ac-6379-4d6d-92ee-14dd35ca779d","details":{"checks":{"database":"unavailable"}}}`. Log satırında yalnızca sabit "Readiness check failed: database is unavailable." mesajı var.
  - `DATABASE_URL=<erişilemeyen port> npm run openapi:emit --workspace apps/api` → iki PostgreSQL container'ı da durdurulmuşken başarılı: "Wrote OpenAPI document to .../apps/api/openapi.json". Belge 162 satır; path'ler `/api/health/live`, `/api/health/ready`; `ApiErrorDto` ve `ApiFieldErrorDto` şemaları var.
  - `npm run typecheck --workspace apps/api` → hatasız. `npm run build --workspace apps/api` → `nest build` hatasız. `npm run lint --workspace apps/api` → 0 uyarı, 0 hata (36 dosya).
