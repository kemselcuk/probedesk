## Amaç

Ortak tasarım tokenları ve Material ölçeği; ana plandaki bu ekrana/bileşene ait ölçü, hiyerarşi ve davranış koruma maddelerinin tamamını uygula. Aşağıdaki özet ana planın yerini almaz.

## Kabul ölçütleri

- [ ] Renk/boşluk/radius/tipografi tek token kaynağı; açık tema; body 14, h1 24, metadata12 px.
- [ ] Material public density/override API ile button 36, toolbar 32 ve field 40 px hedefleri; label/error kırpılmaz.
- [ ] Yerel font/system fallback, uygulamada dış font ağı yok; kontrast ve zoom okunurluğu korunur.
- [ ] Global CSS scale, kök font küçültme, ::ng-deep ve yaygın !important yok.

## Doğrulama ve kanıt

- İlgili Angular testleri, lint/typecheck ve değişiklik alanına uygun build.
- Gerçek browser: ölçü, taşma, label/error/focus ve önce/sonra PNG.
- UI-08 için ana plandaki tam verify/integration/izole E2E paketi.
- Sadece gerçekten çalıştırılan komutun sonucunu yaz; görsel kabulü test yeşiline eşitleme.
