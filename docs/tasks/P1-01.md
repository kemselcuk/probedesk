## Amaç ve çıktı

npm workspace, Angular/NestJS iskeletleri, strict TypeScript ve uyumlu kesin sürümleri kur.

## Değişiklik alanı

- `package.json`
- `package-lock.json`
- `apps/api/`
- `apps/web/`
- `packages/api-client/`

## Kabul ölçütleri

- [ ] Temiz npm ci ve iki uygulamanın build'i başarılıdır.
- [ ] Angular compiler/TypeScript/Node ve Nest/Prisma modül ayarları birlikte doğrulanır.
- [ ] Lockfile ve Node sürüm kaydı vardır; RC veya kontrolsüz latest bağımlılık yoktur.
- [ ] Sadece iskelet ve sürüm doğrulaması yapılır; ilerideki özellikler tamamlanmış sayılmaz.

## Doğrulama

- npm ci; npm run typecheck; npm run build.
- Gerçek sürümleri ve peer uyumluluk sonucunu architecture.md/kanıt kaydına yaz.

Uygulama komutları [test sözleşmesindeki](../testing.md#planlanan-komutlar) planlanan giriş noktalarıdır; henüz var oldukları veya çalıştırıldıkları iddia edilmez. İlgili davranışlar için anlamlı test kullanılır; ilgisiz kontrol tekrarları eklenmez.
