# @probedesk/api-client

The only contract boundary between `apps/api` and `apps/web`.

## Generated REST types

`src/schema.ts` is generated by `openapi-typescript` from `apps/api/openapi.json`:

```bash
npm run openapi:emit        # regenerate the API document
npm run openapi:generate    # regenerate the TypeScript types
npm run openapi:check       # fail if either artefact is stale
```

`src/index.ts` re-exports `paths`, `components` and `operations`. Frontend code
imports these types; it must never import NestJS DTOs or Prisma models.

## SSE types

The OpenAPI generator does not describe `text/event-stream` payloads. When SSE is
implemented (P4-01), its envelope and event payload types will live in
`src/sse.ts` in this package, pinned to `schemaVersion: 1` and covered by the
same review as the REST contract. Until then no SSE types are exported.

## Determinism

The emitter and generator are deterministic: the same application source and
`apps/api/openapi.json` produce identical bytes. `npm run openapi:check` fails
when the committed document or `src/schema.ts` differs from the generated
output, so a contract change cannot land without updating the client.
